# Cafe Collective – QA Portfolio

# Overview

Cafe Collective is a mobile café discovery application focused on location-based exploration, reviews, and user engagement.

I contributed to QA by testing Android and iOS application flows, validating location-based functionality, reviewing UI behavior, and identifying functional and usability issues.

> **Note:** This repository contains QA documentation and portfolio material only. No proprietary source code, credentials, or confidential client information is included.

# QA Responsibilities

* Performed functional, regression, exploratory, and usability testing
* Tested Android and iOS builds
* Validated location-based application behavior
* Tested map and café discovery functionality
* Tested review submission workflows
* Verified authentication flows
* Tested referral and reward functionality
* Reported and tracked issues through Jira
* Performed retesting after fixes
* Collaborated with developers and product stakeholders
